# Customer Satisfaction and Feedback Dashboard (Power BI)

This project is a Power BI dashboard that analyzes customer satisfaction survey data. The dataset includes feedback from 300 customers across different products and global regions. It provides insights into satisfaction levels, Net Promoter Scores (NPS), and feedback trends over time.

## Overview

*Tools Used:* Power BI Desktop  
*Dataset:* Synthetic customer feedback data (CSV)  
*Goal:* Understand customer experience and satisfaction patterns to guide business improvements.

## Key Insights

- *Average Satisfaction Score*
- *Average NPS Rating*
- *Response Count*
- *Satisfaction by Product*
- *NPS by Region*
- *Monthly Trends*
- *Raw Feedback Comments Table*

## Features

- Interactive slicers to filter data by Region, Product, and Date
- KPI cards for quick metric overview
- Clean and organized layout with professional theme
- Ideal for showcasing analytical and visualization skills

## How to Use

1. Download the .pbix file
2. Open in Power BI Desktop
3. Interact with slicers and visuals to explore insights
